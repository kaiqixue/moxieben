# 生产安全验收清单

以下项目需在隔离环境形成验证证据。P0 未通过时，当前版本仅供受限网络中的合成数据测试。

| 级别 | 验收项 | 通过证据 |
| --- | --- | --- |
| P0 | 教师登录、可信会话、退出与撤销 | 每位教师单独账号，禁用开放注册。匿名访问业务页面须登录，匿名 API 统一拒绝，图片、报告和导出也受控。用 Secure、HttpOnly、适当 SameSite 的会话 Cookie，写操作使用会话 CSRF 并验证 Origin，登录限速 |
| P0 | 班级及对象级授权 | 两个教师账号用各自数据验证列表、编号访问、照片、报告、填写/改分、导入、删除、再识别、任务状态/继续、讲评和导出。跨所有者读写拒绝且无数据泄露。后台任务携带经校验的发起者与资源范围，增删权限后重新判断 |
| P0 | 反向代理和端口 | 受信域名和代理头有明确配置，普通客户端无法伪造代理身份。入口只公开 HTTPS 和必要的 HTTP 证书验证/跳转，应用端口和 SQLite/图片目录不可达。CORS 保持同源，禁用 debug 和测试入口 |
| P0 | 秘密管理与出站 | 正式 Token/Key 由运行环境专属密钥文件管理，旧 SQLite 中有值时按迁移方案处理。禁止普通教师改 URL 或触发连通性测试。管理员只能配置核准服务地址，校验目标地址及解析结果，拒绝内网、环回与链路本地等目标，经出站策略约束 OCR API 与结果下载。凭据仅发送给对应服务 |
| P0 | 学生数据外发 | 确认学校允许的 OCR 服务、用途与保留要求。明确上传图可能带姓名、学号与原始元数据。真实样本、日志、备份和凭据不进入 GitHub/镜像。应用日志与代理日志检查脱敏，记录阶段、请求 ID 和结果类别 |
| P0 | 存储及恢复 | 数据卷仅给应用与授权备份账户。容器非 root，镜像和宿主依赖通过漏洞审查；数据和备份加密、恢复经演练；关闭入口后可恢复数据库与图片的一致快照 |
| P1 | 上传与资源限制 | 保留文件格式、魔数、像素和大小检查，限制账号/实例并发和存储配额，测试畸形、超大文件及半途失败的清理与恢复；提交重试不重复占用名额 |
| P1 | 运维与监控 | 公共探活只给最少信息，详细状态限管理员。监控认证失败、OCR 时延/限额、SQLite 锁等待、积压、磁盘、备份和证书。记录关键改判、删除、授权及配置变更的操作者与时间 |

安全测试在隔离实例用虚构联系人和合成照片执行。上线验收除了正常教师操作，还需覆盖无会话、权限收回、归档限制、出站受限和服务重启后的续跑。
