# VLM-REVIEW-01 实施步骤

> 当前行为以文末“自动整批复核修订”为准，前文题数上限与仅整页建议属于历史阶段。

1. 实现独立视觉复读 API。用合成图片和模拟接口验证裁图范围、忠实转录、建议分、失败回退和成绩保护。
2. 在测试环境使用一套支持图片输入的服务，对经过授权的单题样本做真实验证。记录定位失败、错读、时延、调用量和费用。
3. 在核对页复用现有框选操作，加入「视觉复读」和建议区。保存复读记录后，再接入受版本保护的一键采纳和撤销。
4. 用人工基准验证自动单题定位。只为定位明确的异常题接入后台尝试、去重、额度上限及失败回退，先在小范围试点比较教师实际处理时间和误采纳。

## 第一阶段接口

`POST /api/submissions/{sid}/reviews/{qid}/visual-reread`。遵循当前本地应用的同源和 CSRF 校验。JSON 示例：

```json
{"page_id": 12, "box": [120, 430, 490, 580], "rotation": 0}
```

`box` 是原始展示图的四个整数像素坐标，顺序为左、上、右、下。可选 `rotation` 为逆时针角度 0、90、180、270，默认用现有预览方向。框选前应核对只有目标题的作答和必要的定位信息，避开姓名、学号和相邻题。服务器校验照片归属、矩形边界、尺寸及异常状态，首版由调用方确认题目语义和裁图内容。

成功时返回 `id`、`status`、`transcript`、`suggested_score`、`max_score`、`elapsed_ms`、`crop`、`preview_url` 和 `can_adopt`。只有 `readable` 产生建议分。`blank`、`unreadable`、`ambiguous` 需要人工核对。越界或过宽返回 400，找不到题或照片返回 404，状态冲突返回 409，上游失败返回 502，未配置返回 503。有效复读结果单独持久化，刷新只读取结果。

核对页的「框选作答」只标记待发送范围，点击「发送局部图复读」才发出请求。复读与框内的局部 OCR 一致、且框选不与其他题已知区域重叠时，才支持一键采纳。采纳调用 `POST /api/submissions/{sid}/reviews/{qid}`，只传 `{"visual_suggestion_id": 1}`。服务端检查最新建议、答卷版本和教师修改，按当前严格规则计分，保存历史并复用撤销入口。采纳前，建议和原有分数、异常状态分别显示。

在启动网站的服务器进程环境配置 `VLM_REVIEW_BASE_URL`（支持图片的 HTTPS Chat Completions 兼容地址）、`VLM_REVIEW_MODEL`、`VLM_REVIEW_API_KEY`。设置由运行环境注入，密钥不进入请求体、代码库或对话。配置缺失时功能不可用。现有 PaddleOCR 设置保持独立。

## 第一阶段自动准备建议

试点启用 `VLM_REVIEW_AUTO=1` 后，单图或批量后台计分完成时才准备复读建议，每个批改任务最多尝试 8 题。只选已经列为不确定、具有已保存局部 OCR 作答证据的短答题。裁图按单页作答框合并，排除图片顶部、重叠身份文字、邻题和范围过大的裁图。尚未取得可靠单题坐标或识别结果的题继续人工核对。

同一答卷、题目和图片仅自动尝试一次。已保存的建议可刷新读取。复读在计分完成后运行，不阻塞老师人工核对。模型失败仍保留待核对项，老师可以使用手动框选复读。已计分正常题的抽查和自动移出队列尚未开启。

## 2026-11-23 整页多题补充复读

新增 `POST /api/submissions/{sid}/visual-reread-page`，请求 `{"page_id": 12}`。使用设置页独立的 AI 复核配置。教师需启用该配置；整页照片可能包含姓名、学号，发送前界面提示。按照片发送，不混合不同学生。传给模型的只有照片和异常短答题号，不含标准答案、既有 OCR 候选或成绩。图片长边限制为 2400 像素，预览保留原图。

后台沿用单题路径；无法得到安全单题裁图、或旧单题已经尝试过时，尝试整页补充复读，不重新调用云端 OCR。同一页多个异常题一次请求，每次任务的既有题数上限仍生效。单页答卷可在没有单题框时复读；多页答卷必须能从已有题目区域或 OCR 题号唯一判断所在页，否则仍需人工定位。模型只返回指定题号、状态及手写原文，拒绝重复或未知题号以及额外评分字段。

整页复读结果分别保存到既有 `visual_suggestions`，不新增表。清晰结果生成建议分，允许老师对照原图一键采纳，与 OCR 不一致也能由老师确认；采纳后按现有规则计分并退出待核对，保留历史、撤销及版本保护。整页补充结果首版不自动解除异常；原单题路径仍仅在独立局部 OCR 相互印证时自动解除。模型看不清、疑似空白或漏题都保留人工核对。

有效建议重复运行时不再次请求。自动任务失败后不自动重发，发送状态不明的中断仍沿用任务保留标记；老师可在核对题目中点击“整页多题复读”主动重试失败项。错误使用固定类别 `authentication/rate_limit/network/response_format/provider`，不回显上游原始响应或凭据。后台分别展示答卷进度、图片请求次数、有效返回次数、建议题数和自动解决题数。尚无真实服务商计费统计，不虚构调用成本或准确率。

验证：项目 Python 3.11 虚拟环境全量 335 项测试通过，跳过 2 项；另外 53 项 AI、OCR 与归档安全测试通过。模拟浏览器验证单题和整页复读、刷新、采纳、撤销及 390px 无横向溢出。截图保存在 `outputs/page-review/`。全部使用隔离数据库、合成图片和模拟服务；未将现有学生照片发往云端，当前作业 37 道题的实际改善量尚需真实样本验收。

复现：运行 `.venv\Scripts\python.exe -m unittest test_ai_review test_ocr_alignment test_archive_security -q`。浏览器回归沿用 `scripts/recognition_evidence_ui_server.py` 与 `scripts/check_visual_review_ui.cjs`，设置 `RECOGNITION_TEST_PORT` 为非 5000 端口，必要时用 `PLAYWRIGHT_MODULE` 指向已安装 Playwright；只访问该合成测试服务。

### 2026-11-23 接口失败诊断修复

针对页面“12 次图片请求、0 次有效返回、provider”的排查，确认旧分类把 HTTP 400/404/413/5xx、输出截断及配置缺失统一归为 provider，历史记录不能用于区分这些原因。当前本地数据库未保留截图对应任务，不将当前合成测试成功当成那批历史请求成功。使用当前配置和合成图片的 3 次独立请求取得 HTTP 200 及合法结果；没有发送学生原图，也未据此认定真实手写识别准确。

新增中文错误类别，分别说明鉴权、限流、网络、参数拒绝、模型/地址不存在、图片过大、服务异常、返回格式、空响应与输出截断。未知错误仍标记“具体原因未记录”，不猜测。错误消息只由固定文案生成；模型结果刷新后保留诊断说明。设置页测试改用实际整页复读 JSON 格式。

整页输出额度从每题 150 tokens 加 100 调为最低 2048 加每题 256、最高 8000，为包含推理输出的模型保留余量；这只是兼容性改进，不代表历史失败已证实为截断。首个接口失败后停止本任务后续 AI 请求，保护重复计费；失败涉及题数与请求次数分别记录。已失败的旧任务不主动重发。69 项设置、AI、后台任务、OCR 和归档安全回归通过；JavaScript 语法与差异空白检查通过。


## 2026-11-23 自动整批复核修订（当前行为）

- 按产品负责人反馈，取消所有单任务 8 题限制，包括旧配置和旧环境入口；不新增表、不迁移数据。旧 API 的 limit 字段保留兼容，但始终返回 null，不再限制题数；设置页删除题数输入。
- 新上传答卷完成身份匹配、OCR 和批改后，启用的 AI 配置自动进入整批复核阶段。按照片发送全部尚未确认的异常短答，无需打开题目或点击视觉复读。不同学生分开请求，模型仍只转录，不传标准答案和 OCR 候选。
- 自动解除异常要求唯一题号、可靠独立 OCR 作答区域、模型与 OCR 原文一致、版本未变且无教师确认或修改。按原严格规则计分，可能仍判错；原 OCR、复读结果、原自动证据与可撤销历史保留。看不清、无独立证据或冲突的题保留人工核对及可采纳建议。
- 同页连续自动处理不使兄弟题建议失效，多题可分别撤销。已有有效整页建议直接复用，不重复请求；旧单题建议继续供人工使用。已失败建议仅在老师主动发起新补跑后重试。接口错误暂停后续调用，中断不自动重发，保留原防重复提交和归属保护。
- 工作区入口更名“补跑 AI 复核 / 重试失败项”，说明正常上传后自动执行；单题框选保留为无法映射时的补救。只复核异常短答，不自动抽查所有正常题，也不自动处理作文或长翻译。
- 开发验收使用隔离 SQLite、合成照片和模拟模型；测试覆盖一页 10 题仍全部处理、旧 limit=1 不截断、同页混合建议、重复题号不自动确认、旧建议无请求复用、教师并发改判、失败后主动补跑、逐题撤销和幂等。浏览器覆盖配置页无题数输入、原单题/整页操作、刷新、采纳、撤销、1440/390px。真实学生答卷的复核减少量未经本轮测试，不据此宣称识别准确率。

最终验收：当前版本全量 unittest 343 项通过（跳过 2 项）；浏览器验证不打开题目即可后台解除符合条件的异常、复用旧建议不新增模型请求、原手动复读与撤销、设置页无题数限制及 1440/390px。截图位于 outputs/automatic-ai-review/。本地服务已在无运行任务时备份并重启，21 张持久化表内容哈希前后一致，SQLite quick_check=ok；没有发送真实学生照片或主动补跑旧作业。
