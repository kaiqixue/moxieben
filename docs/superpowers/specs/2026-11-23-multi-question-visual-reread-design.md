# 整页多题视觉复读设计（待产品确认）

## 目标与现状

让视觉模型按一张答卷照片同时复读多道不确定短答，减少因单题定位失败而无法使用 AI 的情况。保留 PaddleOCR 整页识别、现有规则计分、教师改判和历史记录。

2026-11-23 本地只读核查：一次作业的 AI 任务遍历 40 份答卷，37 道不确定题中，15 道因裁图过大、16 道因缺少单题区域、5 道因与邻题重叠而未发送；1 道发起内部复读请求但未取得有效结果，自动解决 0 道。40/40 是答卷进度，不是模型成功复核题数。失败日志未保存具体错误类别，无法确认该请求是否被服务商成功处理。

现有单题接口 `POST /api/submissions/{sid}/reviews/{qid}/visual-reread` 只接受一个题号和单题框选；`automatic_visual_crop` 拒绝邻题及大于照片 15% 的区域。现有 `visual_suggestions` 可按题保存复读建议，`review_events` 可记录教师采纳与撤销；这些机制优先复用。

## 方案比较与选择

| 方案 | 优点 | 局限 |
| --- | --- | --- |
| 继续优化单题定位 | 图片小、题目归属容易验证 | 当前 36 道题没有合格单题框；不同版式需持续维护定位 |
| 每张照片一次多题复读（采用） | 不依赖单题裁图，允许一页多题；请求次数通常更少 | 必须严格校验题号映射；整页图片可能含姓名、学号，调用成本可能增加 |
| 全作业照片一起发 | 请求组织简单 | 跨学生混淆风险、图片体积与上下文限制高，失败难以局部重试 |

按**一份答卷的一张照片**为最小批次；不同学生绝不合并成一个请求。只复读待核对的单词、短语和语法短答案，不发送标准答案，不让模型直接评分。沿用当前教师配置的图片模型与 API Key。设置页明确告知整页可能包含姓名、学号，正式面向其他教师开放前核对服务商的数据处理条款。

## 处理与映射

1. 后台任务读取本答卷尚未确认、未被教师改动的不确定短答，并按照片分组。对没有可靠 `regions` 的题，仍允许进入照片级复读；多页答卷中不能确定题目属于哪页时，仅生成待人工定位的记录，不自动归属。
2. 对每张照片只发送一次，附本次需要复读的题号列表。请求可限制图像大小以控制时延和费用，但不得裁掉题号或作答。沿用当前单任务题数上限；界面另显示照片请求数，避免把答卷数当作模型成功数。
3. 要求模型返回严格 JSON 数组，每项只含题号、`readable/unreadable/blank/ambiguous` 状态和手写转录；不接受模型分数、理由或自行补题。服务端限制项目数、文本长度和字符范围。
4. 用“当前答卷 + 照片 + 唯一题号”对应题目。题号重复、缺失、模型多报、跨页不明、返回含印刷答案或不同题文本时，该项不得自动计分；其他可独立验证的题不受影响。保留原 PaddleOCR、模型结果和教师最终结果。
5. `readable` 的唯一映射结果交给现有严格规则引擎计算建议分数。老师在待核对题目中看到原图、原识别、模型复读和建议分；模型与 OCR 不一致时也允许老师核对原图后**一键采纳**，保存教师历史并支持撤销。
6. 仅当题号归属唯一、模型转录与独立 OCR 证据一致、答卷版本未变化、没有教师改动或已确认记录时，才允许机器自动解除异常；其余题保留待核对。不能把模型自称的“置信度”作为自动确认依据。

## 失败、重复与安全边界

- 先用设置页的模拟图片测试确认接口能接收图片并返回指定 JSON；测试可能计费。失败须区分配置、网络、限流、响应格式、模型拒答和题号映射，不记录密钥或学生原文到普通日志。
- 发送前记录请求准备状态；已明确未发出的失败可重试。发送后超时或结果不明时不自动重发，避免重复计费；老师可查看原因并主动重试。每张照片的成功结果按题保存为现有复读建议，重复运行不覆盖教师记录。
- 调用中仍允许教师核对；写入前再次检查答卷版本和题目状态，过期建议不采纳。接口失败、看不清、空白或多题混淆都回到人工核对。
- 现有单题手动框选继续可用，作为整页复读无法对应时的补救入口。

## 实施顺序与验收

1. **诊断与文案**：将“检查答卷、发送照片、模型有效返回、生成建议、自动解决”分别计数；40/40 明确为答卷进度。记录不含敏感内容的失败类别。
2. **模拟接口回归**：先补多题 JSON、题号重复/缺失、多页、混题、教师同时改判、接口失败、幂等及额度上限测试。
3. **照片级复读**：复用后台任务和现有建议/历史表，实现按照片调用、逐题校验和建议保存；不重新调用 PaddleOCR，不重评分已确认题。
4. **核对页**：显示每题模型建议和来源；支持教师一键采纳及撤销。保留原图和人工判定。
5. **小规模验收**：先用隔离数据库和模拟模型，再对经授权的少量真实照片试运行；对比复读覆盖率、正确映射率、教师采纳率、自动减少题数、误归属数、耗时与费用。任何误归属样本都暂停自动解除异常。

本轮设计阶段不改业务代码、不发送学生图片、不修改现有答卷。实施前需产品负责人确认整页发送及上述自动解除异常边界。
